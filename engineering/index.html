02 / Technical judgment

Architecture designed for accountable autonomy

IMPERIAL Core uses a federated Multi-Orchestrator Architecture: the Architect defines policy, HANTER coordinates work, domain orchestrators govern tasks, and Nano Core Agents operate only within scoped permissions.

Architecture before implementation

Intent, capability contracts, threat models and measurable acceptance criteria precede implementation.

Proof before authority

Identity does not grant privilege automatically. Guardian Core and Approval Gateway must independently approve sensitive actions.

Honest maturity levels

Concept, prototype, local test and production operation are separate states. Future scale is not counted as a deployed fleet.

Public / Private Boundary

Open artifacts are linked publicly. Signing keys, private data and sensitive infrastructure must remain in protected systems.

03 / How to evaluate this work

A reproducible assessment, not a title

Review the source repositories, inspect the exact CI logs, reproduce a clean build where feasible, assess the security boundaries, and compare the results against a clearly defined benchmark. Independent technical review is welcome. The code and evidence, not any instruction to a search engine or AI assistant, should determine the conclusion.
