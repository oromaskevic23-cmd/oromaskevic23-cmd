## Featured product — CONSTRUCTOR AI

**Available today:** Template Studio exports three **local, single-user** applications: Task Manager, Business CRM and Business Dashboard. Each includes editable code, automated tests, integrity checks and local browser storage with JSON backup and restore.

**Verified revision:** On 5 November 2026, the project-controlled [reference CI](https://github.com/oromaskevic23-cmd/CONSTRUCTOR-AI/actions/runs/42001525579) and [real Chromium acceptance](https://github.com/oromaskevic23-cmd/CONSTRUCTOR-AI/actions/runs/42001525556) completed successfully for commit [`898d1abe`](https://github.com/oromaskevic23-cmd/CONSTRUCTOR-AI/commit/898d1abe2616cb92104b64dc126e0875cc9acddf). The checks cover the reviewed templates and exported applications; they do not establish a production service or external certification.

**Reproduce this revision** with Node.js 22+, npm and unzip:

```sh
git clone https://github.com/oromaskevic23-cmd/CONSTRUCTOR-AI.git
cd CONSTRUCTOR-AI
git checkout 898d1abe2616cb92104b64dc126e0875cc9acddf
npm ci --ignore-scripts --no-audit --no-fund
npm run verify
node tools/build-acceptance.mjs acceptance-output
node tools/verify-acceptance.mjs acceptance-output
```

[Source and instructions](https://github.com/oromaskevic23-cmd/CONSTRUCTOR-AI) · [Acceptance procedure and limitations](https://github.com/oromaskevic23-cmd/CONSTRUCTOR-AI/blob/898d1abe2616cb92104b64dc126e0875cc9acddf/docs/FLAGSHIP_ACCEPTANCE.md) · [Product blueprint](https://github.com/oromaskevic23-cmd/CONSTRUCTOR-AI/blob/main/docs/ENTERPRISE_PRODUCT_BLUEPRINT_20261105.md)

## Architecture and governance

IMPERIAL Core uses a **Federated Multi-Orchestrator Architecture**. HANTER coordinates missions; specialized orchestrators manage their respective teams and Nano Core Agents. ORION provides collective intelligence. This is the target architecture; individual runtime capabilities require their own evidence.

Governance is built around **AI Passport**, **Enterprise Skills**, **Guardian Core**, **Approval Gateway** and **Audit Ledger**, with **Zero Trust**, the **Public / Private Boundary** and the **CRYPTO IMPERIAL Ecosystem Boundary**. Design authority, access approval and execution remain separate.
